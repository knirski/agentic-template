# Security Policy

## Supported Versions

Security updates are provided for the latest tagged release. Fixes are published as new
releases through semantic-release versioning; earlier releases are not backported.

## Reporting a Vulnerability

Please report vulnerabilities privately using GitHub's private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Include the affected tag, a description of the issue, reproduction steps, and the
   impact you observed.

Reports are acknowledged within 3 business days. We coordinate public disclosure with the
reporter and aim to ship a fix in the next release.
